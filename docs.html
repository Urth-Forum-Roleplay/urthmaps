Measurements

The easiest way to measure area is to use GIMP's Fuzzy Select tool in combination with the Histogram window (Windows > Dockable Dialogues > Histogram). The window displays the number of selected pixels at the bottom.

  • A pixel on the map is equivalent to 6.34126 km² (exactly 50 ÷ 2.808²)
  • The side of a pixel on the map is 2.518 km long (exactly √50 ÷ 2.808)

Tools

Automapper

Automapper (script-fu-automapper.scm) is a GIMP Script-Fu script written in Scheme which automates the creation and export of most supplemental maps.

The script currently updates blank, hydro (swaps base), interactive, locator-global, locator-local, and timezones (swaps base).

Installation

The script can be found here. It should be placed in your GIMP scripts directory, the location of which can be found under Edit > Preferences > Folders > Scripts. If GIMP is open when you install or update the script, you will need to close and reopen the app for the change to take effect.

Usage

Before starting the script for the first time, you should dock the Error console somewhere (Windows > Dockable Dialogues > Error Console) and keep it open. Any messages the script generates will appear there. Once you have that set up, you can start the script under Image > Urth > Automapper. This will open a small window (do not start the script yet).

In the window, you'll have to select:

  • OS: The operating system you're using.
  • Local repository root: The directory (folder) where you keep the local copy of the urthmaps repository (404.html is in there).
  • Enable debugging?: Whether or not to enable debugging. You should keep this disabled, this function is only used to troubleshoot issues and also increases how long the script takes to run.
  • Ready to start?: Checks that you're ready to start so that you don't impulsively or accidentally start the script.

To run the script, you should have urth.xcf open in GIMP and nothing else. Make sure to clean up any temporary layers you added while updating the map. If the script is stopping and you're not sure why (remember to read the error console messages), check the next section.

You can now start the script. The Automapper window will stay open during execution and close when it is done. To see what is going on, check the error console and look at the bottom of your screen.

Troubleshooting

Below is a list of things the script checks for, in order. If the script encounters any of these conditions, it will stop executing.

  • User has not checked the "Ready" checkbox
  • No images are open
  • More than one image is open
  • Open image has unsaved changes
  • Image is not 11232 x 7525 pixels (the size of the political map)
  • Image does not have 6 layers (counting Labels but not its children)
