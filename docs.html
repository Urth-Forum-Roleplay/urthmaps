Measurements

The easiest way to measure area is to use GIMP's Fuzzy Select tool in combination with the Histogram window (Windows > Dockable Dialogues > Histogram). The window displays the number of selected pixels at the bottom.

  • A pixel on the map is equivalent to 6.34126 km² (exactly 50 ÷ 2.808²)
  • The side of a pixel on the map is 2.518 km long (exactly √50 ÷ 2.808)

Fonts

For all fonts, anti-aliasing should be disabled. Text is always in black.

Usage Font Size Note
City Franklin Gothic Book 10 Requires some manual touch-ups
Capital Sans Serif* 20 Underlined
Nation Bell MT Bold 35-75 Sizes by increments of 10 only
Territory Bell MT Bold 25 Italicized

*The Sans Serif we use is more specifically known as "MS Reference Sans Serif" and appears as "REFSAN" in the Windows fonts folder.

Layers

This section indicates the purpose of each layer of the political map and the state of their locks. This locking arrangement is meant to be as unobtrusive as possible when editing the map. In the event lock states do need to be changed during an update, they should be restored as indicated below before pushing the changes.

Layer Opacity Content Position Visibility Alpha Notes
Update Notes 100 🔒 🔒 🔒 Layer over the legend with the "last updated" text
Legend 100 🔒 🔒 🔒 🔒 The legend at the bottom left of the map
Latitude/Longitude 60 🔒 🔒 🔒 The "grid" over the map
Labels 100 Container for the next three layers
National 100 🔒 Nation and territory labels
Cities 100 🔒 City labels (including captials)
Sub-National 80 🔒 Sub-national borders and labels
Political 100 🔒 🔒 Coloured areas, white space, international borders
Ocean 100 🔒 🔒 🔒 🔒 Single-colour background layer
