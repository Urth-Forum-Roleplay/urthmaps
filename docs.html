On this page, you'll find important information about Urth's maps, how they're made, and some helpful tools.

Measurements

The easiest way to measure area is to use GIMP's Fuzzy Select tool in combination with the Histogram window (Windows > Dockable Dialogues > Histogram). The window displays the number of selected pixels at the bottom.

  • A pixel on the map is equivalent to 6.34126 km² (exactly 50 ÷ 2.808²)
  • The side of a pixel on the map is 2.518 km long (exactly √50 ÷ 2.808)

Fonts

For all fonts, anti-aliasing should be disabled. Text is always in black.

Usage Font Size Note
City Franklin Gothic Book 10 Requires some manual touch-ups
Capital Sans Serif* 20 Underlined
Nation Bell MT Bold 35-75 Sizes by increments of 10 only
Territory Bell MT Bold 25 Italicized

*The Sans Serif we use is more specifically known as "MS Reference Sans Serif" and appears as "REFSAN" in the Windows fonts folder.
