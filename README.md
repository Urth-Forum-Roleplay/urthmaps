## About
This repository is maintained by the <a href="https://urthmaps.com/about">Urth Cartography Department</a>. It is used to publish <a href="https://urthmaps.com/">our website</a>, to publish and manage the edit history of <a href="http://urthmaps.com/maps">our community maps</a>, and to host our tools (such as GIMP scripts).
